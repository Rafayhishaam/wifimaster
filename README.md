# 🚀 Advanced Wi-Fi Master Tool (Kali Linux)

An advanced Python-based utility designed for network administrators and Linux users to perform deep Wi-Fi reconnaissance (2.4GHz & 5GHz band detection), secure profile backups, and instant restoration.

## 📌 Key Features
- **Deep Wi-Fi Scanning:** Detects surrounding networks, BSSIDs, channels, frequencies, and precise signal strengths.
- **Band Detection:** Automatically categorizes wireless networks into **2.4 GHz** and **5 GHz** bands.
- **Profile Backup:** Securely backs up connection profiles including encryption keys and passwords.
- **Instant Restore:** Restores network configurations seamlessly after a fresh OS installation or system wipe.
